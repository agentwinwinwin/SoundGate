# Security Policy

## Sensitive data

Do not open a public issue containing credentials, access keys, device tokens, product secrets, user identifiers, production device names, database dumps, or unredacted screenshots.

The repository intentionally excludes local `.env` files. Configure secrets through environment variables or the secret manager provided by the deployment platform.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature when it is enabled for this repository. Include the affected component, reproduction steps, impact, and a minimal redacted proof of concept.

Do not test against devices or cloud accounts you do not own or have explicit authorization to use.
